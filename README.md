# mirinnano.github.io

mirinnano のポートフォリオ兼 About me ページです。

公開URL: https://mirinnano.github.io/

## 構成

- `index.html` — ページ本体
- `assets/style.css` — スタイル
- `404.html` — Not Found ページ

ビルド不要の静的サイトです。ローカルでは次のコマンドで確認できます。

```bash
python3 -m http.server 8000
```

## 独自ドメイン

取得後、リポジトリの Settings → Pages → Custom domain に設定し、DNS を GitHub Pages に向けます。
